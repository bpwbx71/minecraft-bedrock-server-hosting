## 面板服这条路：从购买到进游戏

2022 年那版教程记录的流程是这样的（面板入口文案这几年大概率改过，按钮位置对不上就找同名菜单）：

## 自己搭 BDS：记住四件事就够了

官方基岩版服务端（BDS）是 C++ 写的，Windows 和 Linux 都有开服包，官网下载页当前发布的是哪个版本就用哪个版本。这里不写具体版本号，因为教程里出现的版本号几个月后就过期，照着抄下载链接会 404。

**第一件，放行端口。** 基岩版默认端口是 19132，协议是 UDP。Ubuntu 上用 ufw 的话：

bash
sudo ufw allow 19132/udp
sudo ufw reload


云服务商的控制台安全组里也要放行同一条规则，两处都放行才行。

**第二件，关掉 Xbox 验证。** 编辑 `server.properties`，把 `online-mode=true` 改成 `false`。这一步不做，朋友进来会被挡在验证环节。

**第三件，用 screen 挂着跑。** 直接 `./bedrock_server` 启动，SSH 一断服务就没了。标准做法：

bash
screen -S mc
LD_LIBRARY_PATH=. ./bedrock_server


按 `Ctrl+A+D` 把窗口挂起，SSH 就可以关了；要回后台敲 `screen -r mc`；要关服敲 `screen -S mc -X quit`。

**第四件，客户端手动添加服务器。** 打开游戏，进「服务器」页面，划到最底下点「添加服务器」，面板或日志里给的地址是 `IP:端口` 的形式，冒号前面那段落填「服务器地址」，冒号后面那段填「端口」。

## 连不上，八成是端口协议搞错了

这是基岩版开服最高频的故障，也是最容易白折腾半小时的地方：Java 版是 25565 端口、TCP 协议，基岩版是 19132 端口、UDP 协议。你在网上搜到的教程十有八九是 Java 版的，照着放行 TCP 25565，基岩版客户端当然连不上。

判断方法很简单：客户端提示「无法连接」但服务器日志显示正常启动，先回头检查防火墙规则写的是 udp 还是 tcp；用面板服的读者不存在这个问题，面板直接给出可用的地址和端口，复制粘贴就行。

## 换存档：找对文件夹就行

想把单机玩了几百小时的世界搬到服务器上，面板服的操作路径是：进入实例面板 → 点「文件」→ 下滑找到 `worlds` 文件夹 → 把这个路径下的文件全部删干净 → 上传自己的存档文件 → 重启服务器。

顺序别反。先上传再删除，等于把自己的存档删了。上传前在本地压缩包留一份备份，比什么都稳。

## 服务端不止一种，选错了后面全是坑

基岩版能跑的服务端有好几个，区别主要在于能不能装插件、吃什么资源：

- **BDS（官方基岩版服务端）**：Mojang 官方出的，原版玩法最稳，社区有 bdx、ll 这类第三方插件加载器可以扩展，但加载器本身要折腾。
- **LiteLoaderBDS**：BDS 的重量级插件加载器，提供全 BDS 十几万函数的头文件，功能强，学习曲线也陡。
- **Nukkit**：Java 写的开源基岩服务端，插件生态独立，内存占用小，服务器配置偏低时是个现实选择。
- **PMMP**：PHP 写的，高度可定制，适合有开发能力的人。

一句话结论：只想原版生存，官方 BDS 就够；想装玩法插件又不想换平台，看 LiteLoaderBDS；机器配置紧、预算有限，Nukkit 内存占用更友好。

## Java 版和基岩版能不能一起玩

能，但要额外搭一层。Java 版和基岩版的通讯协议不一样，默认互不连通，现实方案是 Geyser 插件，配多版本插件 ViaVersion 让不同客户端版本都能进。

大致流程是：先用官方服务端核心生成世界并同意 `eula.txt`，再用 BuildTools 构建一个 Spigot 插件核心，把 `Geyser-Spigot.jar` 丢进 `plugins` 文件夹，然后改 `plugins/Geyser-Spigot/config.yml` 里的 `remote: auth-type` 为 `offline`，重启服务器。

这条路比面板服麻烦不少，只在「有朋友坚持用 Java 版」或者「要装 Java 版插件」时才值得走。走过之后你会发现它更适合放在一台完整 VPS 上，面板服的官方基岩版核心做不了这些事。

## 六个容易踩的坑

**关掉正版验证后，所有人皮肤变成默认的史蒂夫。** 这是 `online-mode=false` 的必然结果，装个 SkinsRestorer 这类皮肤插件可以补回来。

**BuildTools 第一次构建会卡很久。** 它需要从外网拉 Maven 和一堆依赖，国内网络下慢得让人怀疑死机。可以先把 `apache-maven-3.9.6-bin.zip` 下好，解压放到 `BuildTools.jar` 同级目录，再给 Maven 配上阿里云镜像源（`http://maven.aliyun.com/nexus/content/repositories/central/`），速度会正常很多。

**面板服开不了公共服。** 带宽、防御、端口都是共享或映射的，几个人玩没问题，真要做几十人的公共服，VPS 或独立服务器才是对的形态。

**教程里的版本号不能照抄。** 2022 年的基岩版教程用的是 1.18 时代的下载链接，现在的客户端连上去大概率版本不匹配。开服包一律去官网下载页拿当前版本，客户端也保持同版本。

**JDK 版本要跟服务端版本对上。** 不同版本的 Java 服务端要求的 JDK 不一样，比如 1.21.3 需要 JDK21，装之前查一下对应版本的 JDK 要求，装错了启动直接报错。

**内存给太少，视距还开很大。** 这两件事是绑在一起的，视距从 10 调到 16，内存和 CPU 的消耗都会上去。低配机器先把视距降下来，比加内存便宜。
